### API·명칭 규정 재점검 (2026-09-16 18시대)

- 실행 중인 4173 서버에서 섬 기본정보 17개 조회 성공. 상세정보 17개는 HTTP 429로 미조회이며 실시간 기본정보로 표시한다. 전체 정상으로 기재하지 않는다.
- 갱신 스크립트에서 운항 예보 9월 16·17일 조회 성공, 18일 데이터 없음. 배편 시간표는 HTTP 429로 전체 갱신이 중단되어 기존 저장본을 보존했다.
- 별도 직접 요청에서 기상청 예보 HTTP 200/resultCode 00, 운항 상태 HTTP 200/resultCode 200 확인. 화면 제공 배편·날씨 JSON은 9월 16일 17:22경 생성본이다. 당일 파일이라는 사실만으로 모든 외부 API가 현재 정상이라고 판단하지 않는다.
- 공식 FAQ의 ‘서비스 내 데이터 출처 표기’ 항목을 브라우저에서 재확인: 기관명 언급 자체의 금지가 아니다. 공사 운영 서비스로 오인시키는 서비스명·로고 사용을 금지하며, 텍스트 출처 표기는 필수다. 현재 `출처: ⓒ한국관광공사`와 독립 서비스 안내를 유지한다. 공식 CI/BI를 추가하지 않는다.
- 개선: 상태 확인 버튼이 관광 API를 실제 조회하고 부분 실패를 표시한다. 상세 미조회 안내를 상세 화면에 추가했으며, 배편·날씨 갱신의 HTTP 429 즉시 재시도를 제거했다.
- 남은 조치: 공공데이터포털에서 관광 상세·여객선 시간표 활용신청 상태와 일일 호출 한도를 확인하고 필요 시 증설 신청. 코드 변경만으로 제공기관 한도를 해제할 수 없다.

2026-09-16 점검: 로그인·SQLite 코드와 DB 조회 도구를 제거했습니다. 배편·날씨는 JSON으로 유지합니다. 실제 갱신 시 관광공사 API에서 HTTP 429(호출 제한)를 관찰했으므로, 호출 한도·운영계정 설정을 확인하고 실시간 조회 성공 여부를 다시 확인해야 합니다. 기존 파일 날짜가 오래되었으면 최신 정보로 간주하면 안 됩니다. 제거한 코드는 웹 폴더 밖 복구용 백업에 보존했습니다.

## 공식 기능설명서 필수란

[공식 양식 ZIP](https://drive.google.com/file/d/1mZ5t_w0Rx21QQ5JOQ5uBMgtn0laixkAF/view)에는 작성용 PPTX와 미리보기 PDF가 있습니다. 표와 필수 항목을 임의로 삭제·변경하지 않습니다. 선택 항목 삭제는 양식 지시에 한정합니다.

- 표지: 팀명, 서비스명.
- 서비스 소개: 서비스명, 유형, 1문장 개요, 선정 이유, 핵심기능.
- 서비스 대표 이미지 1장, 상세 이미지 3~5장.
- 지역특화 선택 시: 특화 지역명, 구현 내용. 여수시를 선택하므로 작성 필요.
- 핵심 기능별 명칭·설명·흐름도 및 화면 캡처. 최대 5개 기능, 양식 슬라이드 복사 허용.
- 실제 활용한 관광공사 OpenAPI 목록과 상세 설명.
- 기타 API·파일데이터 활용 목록. 현재 서비스는 사용하므로 작성.
- 차별성과 발전계획.

[기능설명서 내용 초안](SUBMISSION-DRAFT.md)은 위 순서로 작성했습니다. 공식 PPTX에 옮기고 실제 화면을 첨부해야 제출 가능한 PDF가 됩니다. 아직 최종 제출용 PDF는 완성하지 않았습니다.

## 구현 범위를 과장하지 않기

- 예매는 외부 사이트 안내. 항로 자동 선택·좌석 확인·결제 기능은 없음.
- 운항 필터는 제공된 공공 API 기준. ‘결항 사전 차단’이나 안전 보장 표현을 사용하지 않음.
- 체류시간은 항해시간·복귀 여유를 이용한 추정. 실제 도착시간 보장 아님.
- 난이도·동행·계절 추천은 규칙 기반 추정. 공인 무장애 등급, 정확한 축제·개화 알림 아님.
- 오프라인 여행계획·인쇄/PDF 저장 기능은 제공하지 않음. 지도 타일 저장 기능도 없음.
- 방문 스탬프는 브라우저 자체 기록. GPS 방문 인증이나 기기 간 동기화 아님.
- 로그인·DB를 사용하지 않고 관광정보를 실시간 조회하는 점은 기능설명서에 명시. FAQ는 제안서 개선·변경을 허용하되 기능설명서에 반영하도록 안내함.

## 사용자 확인이 필요한 참가 유의 사항

- 동일 서비스로 해당 공모전 수상 또는 공사 주관 서비스 개발·구축 지원 수혜 여부.
- 동일 서비스를 다른 공모전 부문에 중복 출품하지 않았는지.
- 팀원·제출 내용의 사실 여부와 연락 가능한 이메일.
- 사진·로고·콘텐츠·초상권·소유권에 대한 권리 확인.
- 여러 서비스 유형으로 제출한다면 동일한 내용인지.
- 제출 후 기한 내 첨부 및 접수 결과를 다시 확인. 시스템 과부하·연락 지연은 기한 연장 사유가 아님.
