# 섬으로 기능설명서 내용 초안

공식 PPTX에 옮겨 넣기 위한 초안입니다. 팀명·최종 URL·실제 화면은 확정 전이며 제출용 PDF가 아닙니다. 아래 내용은 현재 구현 범위 기준입니다.

## 표지

서비스명: 섬으로

팀명: 참가 신청 시 등록한 팀명을 확인하여 입력

## 1. 서비스 소개

서비스 유형: 웹 서비스. 로그인 없이 이용 가능.

서비스 개요: 여수 섬 관광정보와 배편·기상 데이터를 함께 확인하고 여행 체류시간을 계산하는 섬 여행 계획 서비스.

주제 선정 이유: 섬 여행자는 관광지 정보뿐 아니라 배편, 날씨, 복귀 시간과 편의시설을 함께 확인해야 한다. 여러 기관에 흩어진 정보를 여수 섬 단위로 모아 탐색 부담을 줄이고 출발 전 확인을 돕는다.

핵심기능:

1. 관광공사 실시간 관광정보 기반 섬 탐색 및 여행 태그 필터.
2. 날짜별 배편·기상 조회와 체류시간 계산.
3. 선택한 섬 주변 숙박·편의점·화장실 지도 검색.
4. 브라우저 내 방문 스탬프·배지와 계절 추천.

대표 이미지 1장: 공개 배포 후 서비스 첫 화면.

상세 이미지 3~5장: 섬 목록·필터, 날씨·체류 계산, 배편 예매 안내, 주변시설 지도, 모바일 스탬프 화면. 오류·빈 화면을 완성 기능처럼 넣지 않는다.

## 2. 지역 특화

특화 지역: 여수시.

구현 내용: 관광공사 지역기반 목록을 여수 지역 코드로 조회하여 섬 관광지를 구성한다. 여수 항로의 배편을 연계하고 섬 좌표를 기상 격자와 주변시설 검색 중심점으로 사용한다. 육로 접근 섬과 배편 확인이 필요한 섬을 구분하여 일정 계획을 돕는다. 섬 수는 실시간 API 응답에 따라 달라진다.

## 3. 핵심 기능별 흐름도 내용

### 기능 1: 섬 탐색과 맞춤 필터

메인 접속 → 서버의 관광공사 지역 목록·상세정보 실시간 호출 → 섬 카드 표시 → 테마·동행·걷기 난이도 선택 → 필터링된 섬 상세 확인.

원본 설명에서 서비스 규칙으로 추천 정보를 도출한다. 난이도·권장시간은 공식 인증값이 아님을 안내한다. API 오류는 재시도로 복구하며 저장된 관광 JSON으로 대체하지 않는다.

### 기능 2: 운항·기상과 체류시간

여행 날짜·섬 선택 → 해당 날짜의 운항·예보 조회 → 가능한 출항시각 제안 → 사용자가 항해시간·안전 여유 조정 → 체류시간 및 복귀 권장 시각 표시 → 배편 클릭 → 외부 예매·선사 확인 안내.

예약 항로 자동 입력·결제는 제공하지 않는다. 공공 운항정보 및 기상은 참고이며 선사 최종 확인이 필요하다.

### 기능 3: 주변시설 지도

섬 상세에서 주변시설 선택 → 선택 섬의 공개 좌표로 지도 이동 → 시설 종류·반경 선택 → 카카오 장소 검색 결과 확인.

사용자 GPS는 요청하지 않는다. 배포 도메인의 카카오 지도 등록을 완료한 뒤 실제 화면을 첨부한다.

### 기능 4: 계절 추천과 방문 기록

계절 추천 확인 → 여행자가 방문한 섬 선택 → 스탬프 기록 → 브라우저 저장 → 기록 수에 따른 배지 표시.

스탬프는 본인 기록이며 위치 인증은 하지 않는다. 계절 정보는 추천 시기이지 실제 행사·개화 알림이 아니다.

## 4. 한국관광공사 OpenAPI 활용

API명: 한국관광공사 국문 관광정보 서비스.

- areaBasedList2: 여수 지역 관광정보 목록과 관련 콘텐츠 조회. 페이지가 여러 개면 추가 조회.
- detailCommon2: 콘텐츠 ID 기준 공통 상세 설명과 위치·사진 권리정보 확인.
- 활용 화면: 섬 목록, 관광 상세, 태그·계절 추천의 근거, 지도 중심 좌표.
- 제공 방식: 사용자 요청 시 서버 실시간 호출. API 인증키는 서버 환경에 보관. 관광 데이터나 호출 통계를 별도 DB에 저장하지 않음.

인증키 원문은 이 문서나 공개 화면에 입력하지 않고 지정된 공식 제출 항목에 직접 입력한다.

## 5. 기타 데이터 활용

- 한국해양교통안전공단 운항 예보·운항 스케줄·운항 상태 API: 날짜별 운항정보와 배편 안내.
- 기상청 단기예보 API: 섬별 격자의 시간대 예보.
- 카카오맵 JavaScript SDK 및 장소 검색: 섬 주변 지도·편의시설.
- DB 미사용: 배편·날씨는 API 생성 JSON 파일로 제공. 스탬프는 브라우저 localStorage.
- 대표 배경사진: Wikimedia Commons의 Geomundo and Baekdo from Bultanbong, Gupdaal, CC BY-SA 4.0. 관광사진은 개별 공공누리 권리정보에 따라 표시.

공식 양식의 기타 데이터 3개 행에는 관련 API를 기관 단위로 묶고 세부 API를 상세설명에 적는다. 필수 항목을 임의로 삭제하지 않는다.

## 6. 차별성과 발전계획

차별성: 섬 선택부터 배편 확인·체류시간 계산·주변시설 조회·여행계획 저장까지 한 흐름으로 제공한다. 관광지 목록만 보여주는 방식보다 섬 여행의 교통 제약을 함께 확인할 수 있다. 모바일에서는 상세 정보를 접어 핵심 내용을 먼저 제공한다.

발전계획: 공개 서비스 운영과 사용성 검증, 선사와의 공식 연동 가능성 확인, 실제 도착시각 기반 계산 개선, 계절 행사 실시간 정보 보강, 접근성 정보의 현장 검증을 순차적으로 검토한다. 지도 오프라인 저장·기기 간 방문 기록 동기화는 이용조건과 개인정보 처리를 검토한 뒤 추진한다. 현재 제공 중인 기능과 구분한다.

제안서 대비 변경: 관광 데이터 DB 구축 대신 공식 FAQ에 맞춘 실시간 API 조회를 적용했다. 오프라인 여행계획·PDF 저장·지도 저장 기능은 제공하지 않으며 실제 방문 인증과 확정 결항 예측도 제공하지 않는다.
