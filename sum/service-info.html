서비스와 데이터 이용 안내

섬으로는 전라남도 여수시의 섬 관광정보·배편·날씨를 함께 살펴보는 독립 웹서비스입니다. 회원가입이나 로그인 없이 모든 기능을 이용할 수 있습니다. 한국관광공사가 개발·운영하는 서비스가 아닙니다.

데이터 출처와 제공 방식

출처: ⓒ한국관광공사

  • 한국관광공사 국문 관광정보 서비스: 여수 지역 관광정보와 공통 상세정보를 서버에서 실시간 호출합니다. 관광정보 DB·JSON을 대신 제공하지 않습니다.
  • 배편: 한국해양교통안전공단 운항 예보·스케줄·상태 API. JSON 파일로 제공하고 날짜가 바뀐 뒤 요청 시 갱신합니다.
  • 날씨: 기상청 단기예보 API. 섬 좌표의 예보 격자로 조회하여 JSON 파일로 제공합니다. 화면에 제공 날짜와 갱신 상태를 표시합니다.
  • 지도·주변 시설 검색: 카카오맵. 검색 기준은 선택한 섬의 공개 좌표이며 사용자의 현재 위치가 아닙니다.

관광 상세정보 조회가 제한되면 실시간 기본정보만 표시하며, 목록 조회도 실패하면 오류와 재시도 버튼을 표시합니다. 배편·날씨는 마지막 저장분이 제공될 수 있으므로 기준 날짜를 확인하세요.

지역 및 관광 설명을 바탕으로 만든 난이도·권장 체류시간·동행 추천은 서비스의 참고용 추정이며, 공인된 무장애 여행·안전 인증이 아닙니다. 계절 추천도 실제 축제 일정이나 개화 알림을 보장하지 않습니다.

사진 이용 안내

관광 사진은 권리정보를 확인할 수 있는 공공누리 제1·제3유형만 표시합니다. 제3유형 이미지는 자르거나 확대하지 않습니다. 사진별 출처와 이용유형을 확인하세요. 기관 로고는 사용하지 않습니다.

개인정보와 방문 스탬프

이 서비스의 애플리케이션 코드는 이름·이메일·계정·GPS 위치를 수집하지 않습니다. 방문 스탬프는 이 브라우저의 localStorage에만 저장되며 서버로 보내지 않습니다. 스탬프 영역의 초기화 버튼 또는 브라우저 사이트 데이터 삭제로 지울 수 있습니다. 스탬프는 직접 기록하는 여행 일지이며 실제 방문 인증이 아닙니다.

회원가입·로그인과 데이터베이스를 사용하지 않으며 별도의 API 호출 통계를 저장하지 않습니다. 지도·외부 사진·예매 사이트 접속 시 해당 제공자에게 통상적인 네트워크 요청이 전달되며 해당 서비스의 정책이 적용됩니다. 실제 배포 호스팅의 접속 로그와 보관 정책은 운영자가 배포 전에 확인해야 합니다.

배편과 여행 안전

본 서비스는 예매·결제 대행을 하지 않습니다. 배편 선택 시 예약 안내를 제공하고 외부 공식 예매 사이트로 이동합니다. 선택한 항로가 외부 사이트에 자동 입력되지는 않습니다. 좌석, 요금, 출항·도착 시각, 입도 가능 여부는 반드시 선사에 최종 확인하세요. 기상청 예보는 선사의 운항 결정이 아닙니다.
